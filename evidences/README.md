# Evidências de execução

Esta pasta é destinada a capturas reais feitas pelo estudante durante a execução no Hermes e no laboratório. **Não coloque imagens ilustrativas como se fossem resultados de execução.**

Sugestão de capturas:

1. `01-hermes-persona.png` — Hermes com o projeto carregado e o agente se identificando como mentor de cibersegurança.
2. `02-sqli-vulneravel.png` — execução local do formulário vulnerável com a entrada de demonstração e o resultado observado.
3. `03-analise-agente.png` — conversa em que o agente explica causa, risco e evidência da SQLi.
4. `04-consulta-parametrizada.png` — trecho de código com a consulta parametrizada.
5. `05-reteste-seguro.png` — execução da mesma entrada no endpoint seguro, com rejeição observada.
6. `06-testes-automatizados.png` — terminal com a execução dos testes e o resultado real.

## Como registrar

- Capture a tela inteira ou o contexto suficiente para identificar o que está sendo demonstrado.
- Não mostre tokens, credenciais pessoais, dados reais ou informações privadas.
- Preserve os arquivos originais das capturas.
- Descreva no relatório o que foi realmente executado; não declare sucesso com base apenas na leitura do código.
- Se um teste falhar, registre a falha e corrija antes de apresentar o resultado final.
